# Leenium

The Leenium Linux payload: commands, configuration, Leenium Shell, themes,
installer core and migrations.

Every Leenium system keeps a root-owned clone of this repository in
`/usr/share/leenium` and updates it from GitHub with `leenium-update`.
Users never edit it; personal settings live in `~/.config`.

Website: https://leenium.drunkleen.com
